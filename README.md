## Prérequis
- Docker et Docker Compose installés sur votre machine.

## Installation et lancement
1. Clonez ce dépôt sur votre machine.
2. Placez-vous à la racine du projet.
3. Lancez simplement la commande :
   ```bash
   docker compose up
   ```
4. Accédez à l'application via votre navigateur à l'adresse :
   **[http://localhost:80](http://localhost:80)**

## Remarque
- La base de données MongoDB peut prendre un peu de temps (environ 1 minute) pour charger toutes les données JSON. Attendez que tout soit prêt avant d'utiliser l'application.
